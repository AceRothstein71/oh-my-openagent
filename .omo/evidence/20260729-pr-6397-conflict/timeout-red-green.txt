Scenario:
A checker crosses the timeout deadline, receives SIGTERM, writes feedback, and
exits with code 2 during the kill grace period.

RED command:

RED result:

Failure:
Expected:
  { "hasComments": false, "message": "" }
Received:
  { "hasComments": true, "message": "late feedback" }

Failing test:
#given checker exits 2 after the timeout deadline
#when SIGTERM closes it during grace
#then it returns the empty result

Interpretation:
The deadline callback sends SIGTERM but does not latch the timeout outcome.
Because the timeout promise resolves only after the grace-period SIGKILL, the
child's code-2 completion wins Promise.race and violates the documented
timeout contract.

Minimum fix:
The deadline callback now latches `timedOut = true` before SIGTERM. A completed
checker result is accepted only when the deadline has not passed. Children
that ignore SIGTERM still wait for the grace callback's SIGKILL before the
timeout promise settles.
